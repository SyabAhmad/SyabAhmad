#### 🔵 3 · MenteE Embed — _research → production_

Compact multilingual text embedding models trained **from scratch** — no borrowed weights: ~41M parameters, 384-dimensional output, Arabic + English + Urdu retrieval, two-stage MLM → contrastive recipe, Apache 2.0.
`PyTorch · Embeddings · Single-GPU training`
**[Research](https://www.menteeai.org/research) · [Models](https://www.menteeai.org/embed-models) · [Preprint (DOI)](https://doi.org/10.5281/zenodo.22117673)**

### 🔬 Research

**`mentee-embed` — competitive multilingual embeddings, trained from zero.**

- 🧠 **~41M params · 384 dims · 3 languages** (العربية · English · اردو) — low-resource languages treated as first-class
- 🥇 Two-stage from-scratch training: masked language modeling, then contrastive fine-tuning — a cheap bootstrap that avoids representation collapse
- 📄 **Preprint:** _mentee-embed-v3_ · Zenodo · 26 Aug 2026 · CC BY 4.0 → **[DOI 10.5281/zenodo.22117673](https://doi.org/10.5281/zenodo.22117673)**
- 📊 **5 publications**, measured numbers instead of marketing — failures documented next to wins, every artifact public

**[Read the research →](https://www.menteeai.org/research)**
